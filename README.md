# Paloma Powell — Portfolio

Página personal de enlaces hecha con HTML, CSS y JavaScript, sin dependencias ni proceso de compilación.

## Personalizar

Abre `index.html` para editar el contenido y los enlaces:

- El botón **Portfolio** todavía apunta a `https://example.com/portfolio`; reemplázalo por el enlace definitivo.
- Los botones de **Galería** y **Hotrack** ya apuntan a sus sitios.
- El botón de correo está preparado y queda pendiente de agregar la dirección de email.
- El botón de WhatsApp abre una conversación con el número configurado en el enlace.

## Uso local

Abre `index.html` en cualquier navegador. Las fuentes tipográficas se cargan desde Google Fonts; si no hay conexión, se usarán fuentes del sistema.

## Publicar en GitHub Pages

En **Settings → Pages**, selecciona la rama principal y la carpeta raíz (`/`).
